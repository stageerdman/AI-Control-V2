# INIT — decisions & lessons

Durable knowledge from this update. Status lives in `update v1.md`; this file is
principles and what-we-learned.

## Founding principles (from the vision)

- **Altitude is a feature.** Orchestrators get the big picture and never the
  details; teams/agents get role-scoped context. This separation is a product
  rule, not just an implementation detail — it must show up in both the data
  model and the UI.
- **Voice is the primary surface, not a bolt-on.** Every core action should have
  a real voice path. A clarifier agent shapes fuzzy intent *before* work starts.
- **Show programs, not terminals.** The user watches progress and state, never a
  raw terminal. "What is this agent doing" and "what can this agent reach" are
  the two questions the UI must always answer.
- **Credentials are global and granted.** Tokens are saved once, globally, and
  granted per agent/project. Never show secret *values* anywhere.
- **Playful is the personality; minimal is the system.** Few primitives, no
  clutter (UX module) — but the product itself should feel alive and fun.
