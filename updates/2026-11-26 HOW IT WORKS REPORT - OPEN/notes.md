# Notes for the "How AI Studio works" report (Elon)

Facts gathered so far (from code):

- Stack: Tauri desktop app (`app/`, React/TS front, Rust shell `app/src-tauri/src/{lib,backend,tray,quit}.rs`) + Node 25 TypeScript backend (`server/`, Fastify, zod, built-in node:sqlite, run from source via tsx, no build). Port 4319, 127.0.0.1 only. CORS: localhost:1420, tauri://localhost.
- `.project`: run `npm --prefix app run dev`, test `npm --prefix server test` (vitest, in-memory sqlite).
- Data: `~/.ai-studio` (studio.db, runs/<runId>.jsonl redacted stream logs, logs/, worktrees/<projectId>/<slug>-<id8>, toolkits/<agentId>, images/, scratch/, server.lock). Projects in `~/dev` (sandbox; every path must resolve inside it, fs/sandbox.ts). Secrets in `~/.ai-control/.env` (0600, atomic); db keeps only metadata + last4.
- main.ts boot: config → ensureDirs → acquireDataLock (server.lock {pid,port}, one backend per data dir) → reaper.sweep leftovers (tagged processes from crashed run) → tag env → openDb → store → secret store → runner (claude-cli / fake / unavailable) → gh → selfInstall (main checkout keeps /Applications/AI Studio.app current after merges) → buildApp → seed + cast packs → import keys → listen. Shutdown SIGINT/SIGTERM: app.close (3 s budget) → reaper.sweep (1 s) → db.close; app hard-kills at 5 s (backend.rs QUIT_DEADLINE).
- quit.rs: one quit path (menu bar, ⌘Q, Dock, logout); once-guard; shows "Pausing your agents…" if stopping >400 ms; quit-note.ts writes a desk note for every live agent.
- Agent run = one headless `claude -p` process (runtime/claude-cli.ts), stream-json in/out, spawned without shell, own process group (detached), env built from scratch, `--restricted`, `--strict-mcp-config` (only the studio MCP server `mcp/ask-server.ts`, stdio, talking back to the backend via URL+run token), `--permission-mode dontAsk`, `--disable-slash-commands`, `--no-chrome`, `--max-budget-usd`, `--session-id`/`--resume`. Tools Read/Edit/Write/Glob/Grep/Bash + allow-list `Bash(git|ls|cat|pwd|mkdir|npm|npx|node *)`. PreToolUse hook shell-hook.ts: git-guard (no force push, only origin, no remote rewiring/delete, no -C), setting prefixes NAME=value (shell-prefix.ts), Mac builds (mac-build.ts). PostToolUse nudge-hook → forget reminder past 120k tokens. Deny rules: PUSH_BACKSTOP; NO_PUSH for runs w/o hook; read-only folders `Edit(//dir/**)`; no .env reads in extra dirs. Reporter runs + WebSearch/WebFetch.
- Caps: agent 120 turns/$10, review 15/$5, orchestrator 6/$2 (API-equivalent size caps; subscription used). limits.ts: builds/research hitting cap carry on in fresh session of same run; stop if 2 sessions in a row without new work (commit/report/desk note) or >10 sessions.
- After result, CLI lingering >10 s gets group killed unless waiting on background tasks (background.ts).
- Crew contracts (orchestrator, Agent Creator): no tools, run in scratch, ONE JSON answer validated by zod, one repair try, 2nd miss = 502. Contracts: setup-chat, mint-agent, mint-team, dispatch (≤8 items, in order, parallel flag, ≤2 at a time per project, one per agent), team-split, collaboration, health, allow-call, help, report-in, mail-triage, creator-chat.
- Director chat "One Send": {reply, work:{goal}|null, staff?, ask?}; whiteboard summary injected every message; session rotated after 12 turns.
- Worktrees: each checklist item own checkout + branch `studio/<slug>-<id8>` in ~/.ai-studio/worktrees. Gates (collaboration): build → review run (verdict approve|changes) → rework (≤ maxSendBacks, default 2; same note twice → back to orchestrator).
- land.ts (Always Merged): merge main into checkout → run `test:` from .project in checkout (10 min timeout, tail 60 lines, CI=1, PORT) → fast-forward main (`merge --ff-only` where checked out, else guarded update-ref); unsaved edits in user folder touched by landing saved as own commit "AI Studio: saved changes found in the project folder"; up to 3 rounds. Conflict → merge-fix back to builder (2 tries) then fail, work kept on branch. After merge, published project auto-pushed. feature ships when goal's items all landed.
- Teams: captain team-split → member subtasks in own checkouts branched off team branch → deliver → captain integrate (may send back once) → gates → land.
- Handovers, cant_do, desk notes/forget (≤5 per run), call_agent/room (approval via allow-call contract), mail/HQ, reports (reporters only, ≤2 per run, secret masked), auto-approve of yes/no asks, pager.
- Start button: desktop → `open` newest .app; website → start run: command with PORT from project block (3100–3999, 5 per project) and wait for port (90 s).
- Reaper: tags children with data dir key, sweeps at boot and quit, plus opened apps.

## DISCREPANCY (weak spot): server/README says "Agents never push" / `git push` denied in every shell; code (claude-cli.ts PUSH_BACKSTOP + git-guard.ts "AGENTS PUSH") lets agents push to own origin. Docs stale.
