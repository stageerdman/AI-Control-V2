# AGENT ARCHETYPES — v1

**Goal:** design 6–10 new agents (archetypes: product visionaries, engineer-founders,
starship crews, space-opera knights and rogues, fairy-tale and theme-park dreamers,
wizarding-school scholars). Each one needs an original name, look, personality, studio role and tools,
with a finished design card the Founders can build from.

## Phases
1. ✅ Research the look system (`hero-svg.ts` kits, slots, palette, server catalog).
2. ✅ Design 9 agents and draw 7 new hats and 9 new tools in the existing kit format (`parts/archetype-gear.ts`).
3. ✅ Render them on real bots (`spike/`). Check every hat on every body, every tool in every colour, and sizes from 48 px to 300 px.
4. ✅ Design cards plus build notes (`design-cards.md`).
5. ⏳ Founders: wire the kits into `hero-svg.ts`, the server catalog and the prototype mirror. Seed the agents.

## Decisions
- No new slots. Everything fits hat, tool, face, body, antenna and colour.
- One existing part is reused: Bramble wears the existing mortarboard.
- Sola has no hat on purpose. Sola's decal is set explicitly.
