## C. Gaps and what to fix, by priority
1. **Reopen the feature honestly.** Set `f-revision-of-ai-communication` back to Now, around 35%. Set
   `f-fix-agent-asks-user-a-question` to Shipped, because the code and test are on master.
2. **Pixel resolves, it doesn't relay.** Change `ask_person`'s `can` line and description to "use the answer to act
   or decide; tell the user the result, not who said what". Add a conversation check for it.
3. **Pixel reads mail in chat.** Add `mail` / `read_mail` director tools over `office/mail.ts`.
4. **A page tool** (`page_user`) for Pixel and every agent, plus "page me when X is done": a one-shot watch on a
   goal or run that pages when it ends.
5. **`file_report` for every work run** (drop the reporter-only check, or allow it when the user asked for it).
6. **Fix the room bug:** make the orchestrator reachable (a `tell_director` tool, as the research suggested), or
   stop listing it as callable.
7. **Calls reach the real running agent** (research F1: nudge hook + `answer_call`), else a stand-in that carries
   the agent's latest delivery and desk note and says it's answering from notes. Merge `CALLS_RULE`.
8. **Talk to a running agent:** a message to an agent that's running becomes a queued note delivered by the nudge
   hook ("suggestion"), not a 409.
9. **Leader powers:** captains get `stop_work` and `interrupt` (stop with a message) scoped to their team. `stop_work`
   takes an optional `message` that is delivered as the reason or left on the desk.
10. **Per-agent roadmap / to-do page** saved with the update (only leaders create one), shown as a paper on the desk.
11. **Communication drawer in Reports** using the existing `/comms` API, plus an objects-and-interactions how-to page.
12. **Conversation checks:** add the 09:02–09:09 stop sequence and the stand-in "I stopped" case. Add CI for `npm test`.
13. **Hire new agents from chat:** Pixel can propose or mint a new Cast agent (`propose_agent`-style tool).
